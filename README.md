# ALMA | Houses by the Water

A premium, cinematic, editorial-style architectural real-estate experience inspired by the visual language, spatial storytelling, and interaction design of **VELA** (Codenform).

---

## Concept & Architectural Vision

Four private residences on the coastal sound, shaped around water, light, and quiet architectural living.

* **The Site**: Four houses on one shoreline, each turned to its own piece of water.
* **The Living Space**: Floor-to-ceiling glass on the lagoon side, monolithic vein-cut travertine on the other.
* **Materiality**: Vein-cut travertine, sustainable natural teak, low-iron structural glass, and hand-patinated bronze.
* **The Terrace**: West-facing 14-meter dark linear infinity pool running directly towards the sunset.
* **The Houses**: Dual-elevation architectural plates for House I through House IV with interactive front/rear elevation flips.
* **Sunset Concierge**: Interactive viewing scheduler for Friday and Saturday golden-hour viewing slots with dynamic WhatsApp routing.

---

## Tech Stack & Architecture

* **Framework**: React 19 (`react`, `react-dom`)
* **Language**: TypeScript with strict interfaces
* **Build System**: Vite 8 with `@vitejs/plugin-react`
* **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`, `tailwindcss`)
* **Motion & Physics**: Motion (`motion`) with declarative springs and `AnimatePresence`
* **Icons**: Phosphor Icons (`@phosphor-icons/react`)
* **Typography**: Cormorant Garamond (Serif Display), Manrope (Grotesque UI & Navigation), Space Mono (Architectural Coordinates & Tabular Specs)

## Getting Started

### Prerequisites
* Node.js 18+ (tested on Node v24)
* npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/mayanktr127/almahouses.git

# Navigate to project
cd almahouses

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
